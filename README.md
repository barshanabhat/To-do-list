# To-do-list
# Collaborative To-Do List REST API

A RESTful API for managing tasks using Node.js, Express.js, MongoDB, and Mongoose.

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- REST Client for VS Code
